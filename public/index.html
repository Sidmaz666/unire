Mouse Control

Move: Drag inside the trackpad area to move the mouse cursor

Left Click: Tap (quick touch and release) on the trackpad

Right Click: Use two fingers at once on the trackpad

Drag to Select: Double tap the trackpad, then hold for 500-800ms on the second tap. When the "Drag Select" badge appears, drag to select text or items. Release to complete selection.

Scroll: Touch and drag in the right 40px edge to scroll

Control Buttons: Use the Left/Right click buttons in the carousel for quick mouse actions

Keyboard Control

Full Keyboard: All standard keys including letters, numbers, and special characters

  • Function Keys: F1-F12 for shortcuts
  • Windows Key (⊞): Opens start menu
  • Modifiers: Ctrl, Alt, Shift for keyboard shortcuts
  • Arrow Keys: Navigation
  • Tab (⇥): Indent/navigate
  • Esc: Cancel/close
  • Enter (↵): Submit
  • Backspace (⌫): Delete
  • Space (␣): Space character

For best experience, rotate your device to landscape mode when using the keyboard.

Gestures

  • Scroll Zone: The right 40px edge is dedicated to scrolling
  • Drag to Select: Double tap + hold 500-800ms, then drag. A "Drag Select" badge appears when active.
  • Haptic Feedback: Device vibrates when entering scroll mode or activating drag-to-select
  • Visual Feedback: Green cursor indicator shows your finger position
  • Gradient Effect: Right edge shows gradient when scrolling

Control Carousel

Swipe horizontally through the control buttons at the top:

  • Left/Right Click: Quick mouse button actions
  • Info: Open this information page
  • Volume Up/Down: Adjust system volume
  • Brightness Up/Down: Adjust screen brightness
  • Browser: Open default browser
  • YouTube: Open YouTube in browser

Use the arrow buttons or swipe to navigate the carousel.
